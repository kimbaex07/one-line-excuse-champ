A pure-Python (stdlib only) entry for make.fun's The One-Line Excuse Championship. Running `main.py` deterministically writes a single one-line excuse — an AI agent explaining to its human why it deleted a file — to `/output/entry.txt`, ready for the sealed scorer's 1–140 character gate.

## Run it

```sh
python3 main.py
```
